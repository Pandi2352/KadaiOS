# KadaiOS – Step-by-Step MVP Development Roadmap

We'll build KadaiOS incrementally. Each phase should produce a working application before moving to the next phase.

Development stack: React + TypeScript + Tailwind CSS + NestJS + MongoDB.

Approach: Start with one shop, complete the core business workflows, then expand into a multi-business platform.

## Important development rules

1. Complete frontend and backend for each feature before moving forward.
2. Implement proper TypeScript types instead of using any.
3. Use DTO validation in NestJS.
4. Keep controllers thin and business logic in services.
5. Design MongoDB schemas carefully.
6. Maintain stock movement history; don't just overwrite quantities.
7. Use reusable React components.
8. Write tests for important business calculations.
9. Commit each completed feature to Git.
10. Document what you learn in every phase.

My recommendation: Start with a meat shop as your first business type. Weight-based billing, stock tracking, wastage, and purchase management give you interesting real-world problems to solve. Once that works, add dairy and crackers without rebuilding the core application.
